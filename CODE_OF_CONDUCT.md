# Code of conduct

This module follows the [Vox Pupuli Code of Conduct](https://voxpupuli.org/coc/), like the
modules in the Vox Pupuli community.

In short: be kind, assume good intent, and keep discussion about the work. Harassment of any
kind is not tolerated in issues, pull requests or any other project space.

Report unacceptable behavior to partners@noderings.com. Every report is reviewed and kept
confidential.
